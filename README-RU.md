# Concurrency Rally: Go vs Python (Трансатлантическая битва I/O) 🏁

Готовый к продакшену бенчмарк, демонстрирующий архитектурную миграцию микросервиса с высокой нагрузкой на ввод-вывод (I/O-bound) с Python (синхронная библиотека `requests`) на Go (конкурентные `goroutines` и `channels`).

---

## Мы решили устроить гонки через океан, получилась лютая международная задержка (Latency)

Этот проект, который я любовно называю «ралли» заставляет оба «движка» запрашивать данные у реальных живых серверов по всему миру — от бразильских байле-фанк лейблов (например, *Love Funk* и *Kit de Pontos*) до обычных сайтов, которыми мы пользуемся каждый день.

Основной упор здесь сделан на обработку следующих проблем:
* **Высокий гео-пинг:** пакеты физически путешествуют по трансатлантическим подводным кабелям.
* **Защита от ботов:** выживание в условиях жесткого rate-limiting (ограничения частоты запросов) от Cloudflare и троттлинга соединений без использования нативных браузерных заголовков (headers).

---

## 📊 Бенчмарки и «полевая проверка»

### Битва за конкурентность
* **Цикл Python:** ~99.88 сек (Линейное блокирование. Скрипт «засыпает», последовательно ожидая ответа (handshake) от международных серверов).
* **Движок Go:** ~1.476275668  сек (Настоящая конкурентность. Запускает асинхронные легковесные потоки для одновременной обработки всех запросов, игнорируя географическое расстояние).

> **Прирост производительности:** Go обошел Python примерно в **66 раз** в условиях реальной сетевой нагрузки с высокой задержкой!

## 🛠️ Технологический стек и CI/CD

* **Go 1.26** (Goroutines, Channels, `sync.WaitGroup`, `httptest` для моков).
* **Python 3.11** (Логика экспорта и сравнения данных).
* **Docker Multi-Stage:** оптимизированная сборка, отделяющая компиляторы от финальных легковесных образов Alpine.
* **GitHub Actions / GitVerse:** воркфлоу автоматического тестирования, запускается при каждом пуше в код (`go test -v`).

## 🚀 Как запустить ралли

Вам не нужно устанавливать Go или Python на свой компьютер. Вся среда, компиляция и выполнение полностью контейнеризированы с помощью многоэтапной сборки Docker (Multi-stage setup).

### 🏁 Команды для запуска

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/tmnts/url-checker-rally
   cd url-checker-rally
   ```

2. **Сборка Multi-stage образа:**
   ```bash
   docker build -t url-checker-rally .
   ```

3. **Запуск ралли и логи в формате CSV:**
   ```bash
   docker run --rm -v $(pwd):/app/out url-checker-rally
   ```

*Примечание: флаг `--rm` автоматически удалит контейнер после завершения работы, а флаг монтирования тома (volume) `-v` безопасно выгрузит файлы `report_py.csv` и `report_go.csv` прямо в корневую директорию вашего проекта.*
